# Jinx Tamagotchi — браузерная версия

## Как запустить
Просто открой `index.html` в браузере.

## Как сделать игру доступной другим
Самый простой путь — загрузить эти три файла (`index.html`, `style.css`, `game.js`) в новый публичный репозиторий на GitHub и включить GitHub Pages.

После публикации получится публичная ссылка вида:
`https://ТВОЁ-ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`

Прогресс каждого игрока хранится отдельно в его браузере через localStorage.

## Важно
В прототипе персонаж сделан как простой оригинальный placeholder. Если проект будет публиковаться публично, лучше использовать собственные/лицензированные изображения, а не официальные материалы Arcane/Jinx без разрешения правообладателей.
