# Jinx Tamagotchi Deluxe
Открой index.html локально или опубликуй папку через GitHub Pages.

Для публичной публикации нужен репозиторий GitHub и Pages: main / root.

Прогресс игроков хранится отдельно в localStorage их браузеров.

Визуальный персонаж в этом прототипе — фанатский стилизованный placeholder; для публичного коммерческого проекта используй материалы, на которые у тебя есть права.
